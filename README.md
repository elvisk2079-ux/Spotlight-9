# Spotlight 9 — тренажёры слов

https://elvisk2079-ux.github.io/Spotlight-9/

Каждая страница — набор упражнений без печатания (карточки, пары, перевод, подстановка, аудио, мемори, сборка слова). Порядок и набор упражнений меняются при каждом запуске.

Слова: `p43/data.js`. Новая страница = новый блок в data.js + копия html.
